PROJECT TITLE:
   IPL Match Win Prediction using Random Forest Classifier

----------------------------------------------------------------
1. WHAT IS THE PROJECT?
----------------------------------------------------------------
This project predicts which team will win an IPL cricket match
based on match conditions like:
  - Which team is batting first (Team 1)
  - Which team is bowling first (Team 2)
  - The venue/stadium of the match
  - Who won the toss
  - What decision was made after winning the toss (bat or field)

It uses a Machine Learning algorithm called Random Forest
Classifier to make the prediction and displays everything on
an interactive web app built using Streamlit.

----------------------------------------------------------------
2. WHAT IS MACHINE LEARNING?
----------------------------------------------------------------
Machine Learning (ML) is a type of Artificial Intelligence
where we train a computer on data so it can learn patterns
and make predictions on new, unseen data — WITHOUT being
explicitly programmed with rules.

Three types of ML:
  a) Supervised Learning   — learns from labeled data (our project)
  b) Unsupervised Learning — finds patterns without labels (clustering)
  c) Reinforcement Learning — learns by trial and error (games, robots)

OUR PROJECT USES: Supervised Learning (Classification)

----------------------------------------------------------------
3. ALGORITHM USED: RANDOM FOREST CLASSIFIER
----------------------------------------------------------------
Random Forest is an ensemble learning method.

Step-by-step how it works:
  Step 1: Take the training dataset (600 IPL match records)
  Step 2: Create many Decision Trees (we used 100 trees)
          - Each tree is trained on a random subset of data
          - Each tree uses random features at each split
  Step 3: To make a prediction:
          - Every tree votes for a winner
          - The team with the most votes wins (majority voting)
  Step 4: Output the winner with probability/confidence

WHY RANDOM FOREST?
  - More accurate than a single Decision Tree
  - Handles overfitting better
  - Works well with categorical data (team names, venues)
  - Gives feature importance scores

----------------------------------------------------------------
4. DATASET USED
----------------------------------------------------------------
Dataset Type: Synthetic (generated programmatically)
Total Records: 600 IPL match records
Features (Input columns): 5
Target (Output column): 1

FEATURES:
  1. team1         - Team batting first (e.g., CSK, MI)
  2. team2         - Team bowling first (e.g., RCB, KKR)
  3. venue         - Stadium (e.g., Wankhede, Eden Gardens)
  4. toss_winner   - Who won the toss
  5. toss_decision - Did they choose to bat or field?

TARGET:
  - winner: Which team won the match

TEAMS IN DATASET:
  CSK, MI, RCB, KKR, SRH, DC, PBKS, RR

VENUES:
  Chepauk Stadium (Chennai), Wankhede Stadium (Mumbai),
  Chinnaswamy Stadium (Bangalore), Eden Gardens (Kolkata),
  Rajiv Gandhi Stadium (Hyderabad), Feroz Shah Kotla (Delhi),
  PCA Stadium (Mohali), Sawai Mansingh Stadium (Jaipur)

----------------------------------------------------------------
5. DATA PREPROCESSING
----------------------------------------------------------------
Machine Learning models only understand numbers, not text.
So we convert categorical text data into numbers using:

  LABEL ENCODING:
  - CSK → 0, DC → 1, KKR → 2, MI → 3, PBKS → 4, RCB → 5,
    RR → 6, SRH → 7
  - bat → 0, field → 1
  - Each venue is also mapped to a number

  TRAIN-TEST SPLIT:
  - 80% data (480 records) → Training the model
  - 20% data (120 records) → Testing the model

----------------------------------------------------------------
6. MODEL TRAINING
----------------------------------------------------------------
  Algorithm  : RandomForestClassifier
  n_estimators: 100 (number of decision trees)
  random_state: 42 (for reproducibility)

  The model learns:
  - Which teams tend to win more
  - Does home venue advantage matter?
  - Does winning toss help?
  - What is the effect of batting first vs fielding first?

----------------------------------------------------------------
7. MODEL EVALUATION
----------------------------------------------------------------
We evaluate the model using ACCURACY SCORE:

  Accuracy = (Correct Predictions / Total Predictions) × 100

  Our Model Accuracy: ~58-62% (realistic for sports prediction,
  since cricket has inherent randomness)

  FEATURE IMPORTANCE:
  - Team 1 and Team 2 are the most important features
  - Venue also plays a role (home advantage)
  - Toss decision has the least impact

11. EXPECTED VIVA QUESTIONS & ANSWERS
----------------------------------------------------------------

Q1. What is Random Forest?
A: Random Forest is an ensemble ML algorithm that builds
   multiple decision trees and combines their predictions
   through majority voting to improve accuracy.

Q2. Why did you use Random Forest and not Logistic Regression?
A: Random Forest handles non-linear relationships and
   categorical features better. It also gives feature
   importance and is more robust to overfitting.

Q3. What is Label Encoding?
A: Label Encoding converts categorical text values (like
   team names) into numerical values so the ML model
   can process them.

Q4. What is Train-Test Split?
A: We divide our dataset into two parts — 80% for training
   the model and 20% for testing it, to evaluate how well
   the model performs on unseen data.

Q5. What is Supervised Learning?
A: A type of ML where the model is trained on labeled data
   (input-output pairs). Our model learns from match records
   where the winner is already known.

Q6. What is Overfitting?
A: When a model performs very well on training data but
   poorly on test data. Random Forest reduces overfitting
   by averaging multiple trees.

Q7. What does Feature Importance mean?
A: It tells us which input features have the most impact
   on the prediction. In our model, Team 1 and Team 2
   are the most important features.

Q8. Why is the accuracy around 58-62%?
A: Sports outcomes have inherent randomness — weather,
   player form, injuries are not in our dataset. 58-62%
   accuracy is realistic and acceptable for IPL prediction.

Q9. What is Streamlit?
A: Streamlit is an open-source Python framework used to
   quickly build interactive web applications for ML
   projects without needing HTML/CSS/JavaScript.

Q10. What is an Ensemble Method?
A: Ensemble methods combine multiple ML models to get
   better predictions than any single model alone.
   Random Forest is an example of bagging ensemble.

12. KEY TERMS GLOSSARY
----------------------------------------------------------------
  - Classification : Predicting a category (win/loss, which team)
  - Regression     : Predicting a number (score, runs)
  - Overfitting    : Model memorizes training data, fails on new data
  - Underfitting   : Model is too simple, poor on both sets
  - Accuracy       : % of correct predictions
  - Feature        : Input variable used for prediction
  - Target/Label   : The output we want to predict
  - Encoder        : Converts text to numbers for ML models
  - Ensemble       : Combination of multiple models
  - Bagging        : Bootstrap Aggregation (used in Random Forest)
  - Decision Tree  : A flowchart-like model making split decisions
  - n_estimators   : Number of trees in Random Forest
  - random_state   : Seed for reproducibility of results
